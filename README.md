# ФайлыПро — магазин цифровых файлов по подписке

Готовый интернет-магазин: витрина с тарифами подписки → оплата через **ЮKassa** →
выдача доступа к файлам (презентации, таблицы Excel, прочие материалы) в личном кабинете.
Плюс админ-панель для управления продуктами, тарифами и загрузки файлов.

## Быстрый старт (локально)

Нужен **Node.js 18+**. Запуск:

```
npm install
npm start
```

Откройте http://localhost:3000

Админ-панель: http://localhost:3000/admin.html
Вход по умолчанию: `admin@example.com` / `admin12345`
**Сразу смените пароль** (см. ниже).

## Настройка ЮKassa (оплата)

1. Зарегистрируйтесь в ЮKassa (https://yookassa.ru) и подключите магазин.
2. Получите **shopId** и **секретный ключ** (раздел «Настройки → Ключи API»).
3. Создайте файл `.env` (скопируйте из `.env.example`) и заполните:

```
YOOKASSA_SHOP_ID=ваш_ид
YOOKASSA_SECRET_KEY=ваш_секретный_ключ
BASE_URL=http://localhost:3000   # после публикации — ваш домен
```

4. В личном кабинете ЮKassa укажите **HTTP-уведомления (вебхук)**:
   `ВАШ_АДРЕС/api/webhook/yookassa`
   (например `https://shop.example.com/api/webhook/yookassa`). Подпись проверяется автоматически.

5. Перезапустите сервер.

> Для тестов ЮKassa даёт **тестовый ключ** и тестовую карту — оплату можно проверить
> не выводя деньги. Рабочие ключи включаются после модерации магазина.

## Личный кабинет клиента

- Регистрация → выбор тарифа → оплата через ЮKassa → автопереход в кабинет.
- В кабинете видно активные подписки и список доступных файлов с кнопками «Скачать».
- Доступ к файлам открыт только при активной подписке, покрывающей категорию файла.

## ИИ-конструктор презентаций (/create.html)

Покупатель вводит **тему** и **критерии** → ИИ составляет структуру → сайт собирает
и отдаёт готовый `.pptx` в космическом оформлении, файл сохраняется в раздел «Мои презентации».

Для работы нужен ключ любого **OpenAI-совместимого API** (GigaChat, YandexGPT, OpenRouter…):

```
AI_API_KEY=ваш_ключ
AI_BASE_URL=https://openrouter.ai/api/v1
AI_MODEL=название_модели
```

Без ключа страница студии откроется, но генерация вернёт подсказку, что ИИ не настроен.

## Админ-панель (/admin.html)

- **Обзор** — число пользователей, выручка, список заказов.
- **Продукты** — создать продукт, загрузить файл к нему, удалить.
  Доступ к продукту определяется его категорией (`Презентации / Таблицы Excel / Прочие файлы`).
  Опция «free» открывает файл без подписки.
- **Тарифы** — создать тариф: название, цена, срок, какие категории он открывает.

Загруженные файлы хранятся в `uploads/products/`.

## Изменение пароля администратора

Отредактируйте `ADMIN_EMAIL` / `ADMIN_PASSWORD` в `.env` и **удалите** файл `data/db.json`
(или файл `admin` в нём). При следующем запуске админ создастся заново. Не удаляйте db.json,
если у вас уже есть клиенты — при этом сбросятся все подписки.

## Публикация в интернете

Варианты хостинга для Node-приложений:
- **Облачный хостинг** (Render, Railway, Fly.io) — проще всего: подключите репозиторий,
  укажите команду `npm start`, задайте переменные окружения из `.env`.
- **VPS/сервер** (Ubuntu): скопируйте папку, `npm install`, `npm start`, настройте
  Nginx `proxy_pass` на `localhost:3000` и SSL (Let's Encrypt). SPA отдаётся статически.
- **Общий хостинг без Node** не подойдёт — нужен Node-сервер.

После публикации обязательно укажите в `.env` реальный `BASE_URL` (домен) и обновите
адрес вебхука в ЮKassa, иначе редиректы оплаты будут вести на localhost.

## Структура

```
subscription-shop/
├─ server.js          # запуск сервера Express
├─ config.js          # настройки + загрузка .env
├─ api.js             # все API-роуты (каталог, подписки, вебхук, админка)
├─ lib/
│  ├─ db.js           # JSON-хранилище + хэширование паролей
│  ├─ yookassa.js     # интеграция ЮKassa (платежи + проверка вебхука)
│  ├─ ai.js           # ИИ-клиент (OpenAI-совместимый API)
│  └─ presenter.js    # сборка .pptx из плана слайдов (космический стиль)
├─ public/            # фронтенд (витрина, студия, кабинет, админка)
├─ uploads/products/  # загруженные файлы
├─ data/db.json       # данные (создаётся автоматически)
├─ .env.example       # шаблон настроек
└─ start.bat          # быстрый запуск в Windows
```
